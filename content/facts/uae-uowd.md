## Не публиковать

- **«Бакалавриат за 3 года» для абитуриентов из СНГ и Нигерии** — им доступен только 4-летний путь с Integrated Freshman Year.
- **Итоговые суммы «за весь курс»** как официальные — это наши расчёты (цена за предмет × число предметов); указывать с пометкой «ориентировочно».
- **Даты Winter 2027, дедлайны, application fee, цены 2027/28** — не опубликованы.
- **QS =184, 83% трудоустройства, 3 500 студентов** — только «по данным университета».
- **«Аккредитован TEQSA»** про сам UOWD — неточно (см. расхождение 2).
- **Скидка 10 000 AED на IFY** — маркетинговая акция «limited seats», может закончиться.
- **Агентская информация** (комиссии, Agent Resource Portal) — только для команды.
