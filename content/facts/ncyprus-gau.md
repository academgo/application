# Fact sheet: GAU — Girne American University (Girne Amerikan Üniversitesi), Северный Кипр

**Проверено:** 2026-09-22 · **Для:** карточка вуза RU (СНГ) + EN (PK, IN, NG, BD, EG, GCC); набор 2027/28 (действующий прайс на сайте — 2025/26) · **Проверял:** Claude (WebSearch + WebFetch)
**Страновые факты** — в `north-cyprus-recognition.md` (NC-xx) и `north-cyprus.md` (NCY-xx). Цены GAU уже частично там: NC-50, NCY-13, NCY-19, NCY-20.

**Легенда статусов**
- ✅ — первоисточник открыт и прочитан (gau.edu.tr, dorms.gau.edu.tr)
- 🟡 — вторичный источник (Википедия, агрегатор, выдача поиска), данные вуза о себе без проверки, устаревшая страница или вывод
- ❌ — распространённое утверждение неверно; в «Значении» — правильное
- ❓ — не подтверждено, **не публиковать**

> **Главное до написания карточки.**
> 1) Скидка **50% всем иностранцам** на бакалавриат и магистратуру теперь подтверждена официально (GAU-15; снимает 🟡 с NC-50). Исключения для медицины/фармации на странице **не указаны**.
> 2) Официальная таблица цен — **всё ещё 2025/26** (GAU-14). Цены 2026/27 не опубликованы.
> 3) **«All payments made to the University are non-refundable»**, депозит невозвратный (GAU-26). Возврат при отказе в визе на официальных страницах не описан.
> 4) Признание: YÖDAK + YÖK по договору Турция–ТРСК (NC-02…NC-06). Основатель-ректор GAU сам говорил о прекращении признания дипломов ТРСК рядом стран Ближнего Востока (NC-25, NC-58) — важно для EN-аудитории (EG, GCC).

## Не публиковать

- **Цены 2026/27–2027/28** — не опубликованы; давать цены 2025/26 с пометкой (GAU-14, GAU-14a).
- **«Медицина со скидкой 50%»** и **«100% стипендия на медицину»** — не подтверждено для 2027/28 (GAU-16, GAU-21). Стоматологию в GAU не заявлять (GAU-11).
- **«22 000 студентов из 135 стран»**, зарубежные кампусы (Кентербери, Сингапур, США) — не использовать без актуального подтверждения (GAU-04, GAU-05).
- **«Аккредитован YÖK / UK ENIC»** — нет (GAU-07; NC-18). Программные аккредитации не заявлять (GAU-08).
- **IELTS 6.0 / TOEFL 500** из NCY-19 — устарело; писать по GAU-25.
- Для команды: «все платежи невозвратные» (GAU-26) — предупреждать клиента до оплаты депозита. У GAU есть собственная сеть представителей (GAU-34) — конкуренция агентству.
- Для EN-аудитории (EG, GCC): не обещать признание в Египте/ОАЭ — см. GAU-09 (NC-25).
