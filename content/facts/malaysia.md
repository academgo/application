# Малайзия: проверенные факты для SEO-страниц (RU/EN)

**Дата проверки:** 21.09.2026. **Целевые интейки:** 2027 (у частных вузов и филиалов несколько интейков в год: январь / апрель–май / июль / сентябрь, у каждого вуза свой набор).
**Основа:** дайджест `docs/_analysis/digest/МАЛАЙЗИЯ.md`, разделы 1, 4, 5, 8, 9.

**Условные обозначения:**
- ✅ подтверждено первоисточником (страница или PDF открыты во время проверки)
- 🟡 подтверждено вторичным источником (СМИ, агрегатор, консультант, юрфирма) или значение приблизительное
- ❌ в исследовании клиента ошибка; в таблице указано правильное значение
- ❓ подтвердить не удалось, публиковать нельзя

**Для кого:** RU = СНГ (РФ, BY, KZ, UZ, KG, AZ); EN = международные абитуриенты (PK, IN, NG, BD, EG, GCC); оба = и те, и другие.

**Валюта:** MYR = RM (ринггит). Курс на сентябрь 2026 ≈ 4,05–4,10 MYR за 1 USD (MY-94). Вузы в прайсах пересчитывают по «индикативному» курсу 3,80, поэтому их суммы в USD **занижены** примерно на 7% относительно рынка. На сайте суммы давать в MYR, USD — только «≈» с датой курса.

## Не публиковать / формулировать осторожно

1. **Санкционные схемы оплаты** (P2P-USDT, Binance/Bybit, UnionPay Газпромбанка, «оплата через европейские счета для обхода санкций») — не публиковать ни в каком виде. Только нейтрально: «оплата банковским переводом в MYR; при сложностях с переводом — консультация».
2. **«Страшилки» из Д1** («депортация за 72 часа», «порка», «депортационный лагерь», «пожизненный бан за наркотест», «до 30% задержек из-за фото», ложноположительный ТБ «из-за БЦЖ») — не подтверждены. Писать фактами: медосмотр в течение 7 рабочих дней, апелляция в течение 3 дней (MY-36, MY-37).
3. **Шкала EMGS 10% → 100% со сроками по этапам** — неофициальная (MY-17). Можно писать «в личном кабинете EMGS статус показан в процентах», без норм по дням.
4. **Сроки безвиза для KZ, UZ, KG, BY, AZ, EG** — в первоисточнике не найдены (MY-04). Для RU — «до 30 дней» с пометкой «туризм».
5. **Пороги Employment Pass** подтверждены только юрфирмами. Дата 01.06.2026 официальная. Перед публикацией сверить с полным документом ESD (MY-88).
6. **Налоги (182 дня / 30%)** — со ссылкой на LHDN и дисклеймером «не является налоговой консультацией» (MY-89).
7. **Иждивенцы бакалавров** — IMI разрешает только Master/PhD; оговорку EMGS о «17 странах» не публиковать без первоисточника списка (MY-23).
8. **Рейтинги** (Taylor's QS #253, APU #597, UM топ-60) — в этой проверке не сверялись, брать только с topuniversities.com.
9. **Цены Nottingham, Curtin, Swinburne, Southampton, Xiamen, UCSI** — собрать официальные прайсы перед карточками (MY-80, MY-82). Цены на 2027 у большинства вузов ещё не опубликованы: писать «прайс 2026, на 2027 возможна индексация».
10. **«Диплом филиала идентичен головному», «Малайзия на дипломе не указывается»** — не подтверждено (MY-62).
11. **Комиссии, агентские порталы, ЛПР** (раздел 8 дайджеста) — только для внутреннего использования.
12. **Graduate Route после 2+1** — не обещать: нужно ≥12 месяцев в UK (MY-60).
13. **«Special Pass на 30 дней по прилёту»**, SWIFT-лимит 50 000 MYR, тарифы TNB — не проверены, не публиковать.
