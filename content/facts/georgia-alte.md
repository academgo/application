> **Главное до написания карточки.**
> 1) Цены (USD/год, год на страницах не указан): **MD $5 950, стоматология $4 500** (закрывает пробел GMED-29), Computer Science $3 500, BBA $3 500, AI & Data Analytics $3 950 (ALTE-15…ALTE-19).

## Не публиковать

- **WHO / NMC / ECFMG / WFME / ENQA как «аккредитации» Alte**, «диплом признан в Индии, Турции, всей Европе» (ALTE-10…ALTE-12). Только формулировки GMED-08.
- **«No Entrance Exam»**, «все курсы на английском» — с лендинга; неверно (ALTE-13, ALTE-24; грузинский в клинике — GMED-05).
- **Год основания** — источники Alte расходятся (2001 / 23 / 25 лет); прежнее название «Tbilisi Open University» — только агрегаторы (ALTE-02).
- **«3 000 студентов из 50 стран», «2900+ выпускников», «largest healthcare provider», «exclusive»** — самоописание (ALTE-03, ALTE-07).
- **BBA (ENG)** — программа в процессе аккредитации (ALTE-18).
- **Цены «на 2027/28»** — год на страницах не указан; писать «действующая цена по сайту Alte на 09.2026».
- **Стипендия VIAN «на весь первый год»** — условия и доступность иностранцам не раскрыты (ALTE-30).
- **«45 дней» для ВНЖ** — использовать 40 дней по SDA (ALTE-32, GE-22).
- **Application fee $250 только для прямых абитуриентов** и наличие агентского канала — для команды, не для сайта (ALTE-27, ALTE-33).
