# Fact sheet: UB — Universitat de Barcelona

**Проверено:** 22.09.2026 · **Для:** карточка вуза RU (СНГ) и EN (PK, IN, NG, BD, EG, GCC) · **Целевой приём:** 2027/28 (действующие данные — 2026/27) · **Проверял:** Claude (WebSearch + WebFetch, PDF распакованы локально)
**Страновые факты** (виза, работа 30 ч, омологация, UNEDasiss, IPREM, стоимость жизни, каталанский) — не дублируются, см. `spain.md` (ID ES-xx).

**Легенда статусов**
- ✅ — первоисточник открыт и прочитан (ub.edu, gencat.cat, DOGC, сайт рейтинга)
- 🟡 — вторичный источник, выдача поиска, данные вуза о себе без внешней проверки, либо значение приблизительное / год не указан
- ❌ — в исследовании клиента ошибка; в колонке «Значение» указано правильное
- ❓ — не подтверждено, **не публиковать**

> **Ограничение проверки.** Новый портал **web.ub.edu** закрыт защитой от ботов (Cloudflare, HTTP 403) — ни WebFetch, ни curl его не открыли; часть старых страниц www.ub.edu выдаёт «Pàgina temporalment no disponible». Поэтому данные о приёме в магистратуру, жилье, стипендиях и числе студентов по данным самого UB — в основном 🟡 (выдача поиска). Цены, указ о ценах, рейтинги, правила доступа Каталонии и колледж Penyafort открыты напрямую.

> **Главное до написания карточки.**
> 1) **UB — №1 в Испании по QS 2027 (=165) и THE 2026 (=145).**
> 2) **Бакалавриат для не-ЕС стоит как для местных:** 17,69 €/кредит → ≈1 061 € + сборы ≈141 € = **≈1 200 €/год**. Это исключение: указ Каталонии разрешает вузам брать с не-ЕС до 100% себестоимости, и UB делает это в магистратуре (82 €/кредит против 19,37 € для ЕС/резидентов).
> 3) **Язык — каталанский и испанский;** официальная цель Каталонии на 2025/26 — 80% часов бакалавриата на каталанском (ES-73). На английском — отдельные программы (в основном магистратуры).
> 4) Бакалавриат для не-ЕС: омологация + **обязательные экзамены** (PAU в Каталонии или PCE UNEDasiss), preinscripció 2–26 июня. «Поступления без экзаменов» для не-ЕС нет.
> 5) Магистратура: preinscripció открывается в **январе**; не-ЕС советуют подавать в 1-й период. Сбор за заявку — 30,21 €, за проверку не-ЕС диплома — 218,15 €.

## Не публиковать / формулировать осторожно

- **Точная дата основания** — писать «1450 г.» (день в источниках расходится).
- **Численность студентов** — только THE (45 016, 12% иностранцев) или «по данным университета».
- **«Обучение в UB на английском»** — только по конкретным программам; по умолчанию каталанский + испанский.
- **Цены 110 €/95 €** — список UB помечен как 2025/26; перед публикацией сверить по странице программы.
- **Периоды подачи в магистратуру** — только «с января, у каждой программы свои сроки; не-ЕС — в первый период».
- **Возврат сбора при отказе в визе** (UB-29) — сверять по программе.
- **Стипендии UB для иностранцев, служба жилья, квоты для не-ЕС** — не подтверждены (UB-21, UB-40, UB-46).
- **Агентская политика / комиссии** — данных нет.
