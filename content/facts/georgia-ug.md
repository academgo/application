> **Главное до написания карточки.**
> 1) Прайс UG **без указания учебного года**; MD — $6 500, стоматология — $6 000, большинство BA/MA — $4 000 (UG-17…UG-20).
> 2) Приём **круглый год**, два набора (осень, весна), жёсткого дедлайна нет. Для визы платится часть суммы, **весь первый год — до подписания контракта** по приезде (UG-23, UG-27).
> 3) Общежития **нет** («University housing is under construction») — только помощь с временным жильём (UG-33).
> 4) Страница «International Accreditation» содержит **устаревшие и некорректные** формулировки (MCI упразднён; «член ENIC-NARIC» — вузы членами сети не бывают). Не переносить (UG-11…UG-13).
> 5) UG публикует **список своих агентов** (29 позиций, в т.ч. Индия, Нигерия, Ирак) — это конкуренты (UG-35).

- **MCI/NMC, ENIC-NARIC, WHO** — формулировки со страницы International Accreditation UG (UG-11, UG-13). Про медицину — только по правилам `georgia-medicine.md` (GMED-08, GMED-19…GMED-22).
- **Рейтинги Webometrics, «крупнейший частный вуз», «8000 студентов»** — самоописание без даты (UG-04, UG-07).
- **Год основания 2004** — только Wikipedia (UG-02); если нужно — «основан в 2000-х».
- **Срок авторизации NCEQE** — не найден (UG-10).
- **Цены «на 2027/28»** — писать «действующий прайс по сайту UG на 09.2026» (UG-29).
- **«Общежитие»** — нет (UG-37).
- **Список агентов UG и контакты менеджеров** — для команды, не для сайта (UG-38).
- **Банковские реквизиты UG** — не публиковать; оплата только по инструкции вуза в личном кабинете.
