> **Главное до написания карточки.**
> 1) METU NCC — **не вуз ТРСК, а кампус турецкого государственного METU (ODTÜ, Анкара)**. Диплом METU за подписью ректора METU, выпускной в Анкаре (NC-09). Это главное отличие от остальных вузов Севера: не нужно объяснять «диплом ТРСК → denklik».
> 2) Прайс: **$9 450/год + $500/семестр** регистрационный сбор; стипендии **25 / 50 / 75 / 90 / 100%** по результатам SAT / ACT / IB / A-Level и т. п. (конкурс). Сохранить стипендию — CGPA ≥ 2,00.
> 3) Приём по критериям **страны окончания школы** (отдельные страницы по странам), плюс SAT/ACT/IB/A-Level/TR-YÖS. Обязательность SAT для аттестатов СНГ/PK/NG **не подтверждена** — сверять страницу страны.
> 4) Кампус маленький (~3 150 студентов), программы — инженерия + несколько социальных. **Медицины нет.**
> 5) Дедлайны 2027/28 не найдены.

## Не публиковать

- «$6 300» как общую цену (MNCC-19); «$100–120 в месяц на жизнь» (MNCC-38).
- Chemical и Petroleum Eng. как доступные для набора 2027/28; ABET для Aerospace / Industrial / Software (MNCC-12, MNCC-15).
- «SAT обязателен» / «SAT не нужен» для конкретной страны — до сверки страницы страны (MNCC-32).
- Дедлайны, application fee, Duolingo, цена подготовки, прайс 2027/28 (MNCC-24, MNCC-25, MNCC-34, MNCC-36).
- Условия и страны агентов METU NCC (MNCC-39) — для команды: у вуза есть агентская сеть, в карточке не упоминать.
- Не писать «аккредитован YÖDAK» (MNCC-16) — писать «кампус турецкого государственного университета METU».
